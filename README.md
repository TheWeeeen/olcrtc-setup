# olcrtc-setup

Скрипт, который поднимает на VPS туннель **olcRTC** — трафик едет внутри обычного
WebRTC-видеозвонка (Jitsi и другие), поэтому для сети он выглядит как звонок, а не
как VPN.

Это **не обход белых списков** и не эксплойт. Обхода тут нет: выбирается сервис
видеозвонков, который в белом списке у твоего оператора, и трафик заворачивается
в него. Если у оператора нет в списке ни одного живого звонкового сервера — работать
не будет.

Движок — чужой, из проекта [ghostlane-project/olcrtc](https://github.com/ghostlane-project/olcrtc)
(Apache-2.0 / WTFPL у апстрима). Здесь только обвязка: сборка, генерация конфигов,
systemd-юнит, бенчмарк хостов. Схема такая:

```
приложение -> SOCKS5 -> olcrtc cnc -> видеозвонок (Jitsi) -> olcrtc srv -> интернет
```

## Быстрый старт

На VPS (Ubuntu/Debian/Fedora/Arch, root):

```sh
git clone https://github.com/TheWeeeen/olcrtc-setup
cd olcrtc-setup
sudo ./setup.sh --mode srv --host meet.egovm.ru
```

Скрипт поставит Go (если бинаря нет), соберёт `olcrtc`, сгенерирует ключ и комнату,
положит конфиг в `/etc/olcrtc/srv.yaml` (права 600), поставит systemd-юнит
`olcrtc-srv` в автозапуск и **напечатает блок для клиента**: ссылку `olcrtc://` и
готовый `cnc.yaml`.

На телефоне/ноуте — второй вариант, если хочешь поднять клиент вручную:

```sh
./setup.sh --mode cnc --host meet.egovm.ru --room olcrtc-1a2b3c4d --key <hex64>
./olcrtc/cnc.yaml   # запускается командой: olcrtc ./olcrtc/cnc.yaml
```

После запуска клиента появляется SOCKS5 на `127.0.0.1:10808` — его и указывать
в браузере / приложении.

Проверка, что туннель живой:

```sh
curl --socks5-hostname 127.0.0.1:10808 https://icanhazip.com
```

Должен вернуться IP твоего VPS.

## Выбор хоста (важно)

Хосты звонков живут и умирают, и не каждый проходит у твоего оператора.
`bench.sh` перебирает список и показывает, какие поднимаются:

```sh
./bench.sh
# ХОСТ                               СТАТУС   ЗАДЕРЖКА  IP_ВЫХОДА
# meet.egovm.ru                      OK       1.2s       37.120.191.110
# meet.mamba.group                   FAIL     —          —
```

Рабочий хост подставляй в `--host`. Список хостов апстрима:
[`docs/jitsi.instances.yaml`](https://github.com/openlibrecommunity/olcrtc/blob/master/docs/jitsi.instances.yaml).
Транспорт по умолчанию `datachannel`; если не проходит — пробуй `vp8channel`.

## Что нужно

- VPS с root. Наружу открывать порты **не нужно** — сервер сам звонит в комнату.
- RAM: при сборке из исходников нужно ~4 ГБ или swap. Скрипт предупредит и с `--swap`
  создаст swap-файл 4 ГБ. Готовый бинарь можно положить в `/usr/local/bin/olcrtc`
  и запускать с `--no-systemd` без сборки.
- Go 1.26+ — скрипт скачает сам, если его нет.

## Безопасность

- Ключ + комната = пароль от туннеля. Кто их знает — ходит через твой сервер.
  Конфиги пишутся с правами `600`, в выводе ключ маскируется (`--show-key` покажет).
  Не пересылай блок «ДЛЯ ДРУГОГО УСТРОЙСТВА» в чаты и не показывай на стриме.
- SOCKS5 слушает `127.0.0.1` — снаружи в него не зайти. Если очень нужно наружу,
  то только с `--socks-user/--socks-pass` и с фаерволом, иначе это открытый прокси.
- Сервер не пускает клиента в свою локальную сеть и в служебные диапазоны
  (loopback, private, `100.64.0.0/10`, метаданные облака) — это логика апстрима.
- Трафик внутри звонка шифруется (XChaCha20-Poly1305 в OLC2), но это не значит,
  что он невидимый: сам факт звонка на конкретный сервер видно провайдеру.

## Опции

`./setup.sh --help`. Основное: `--mode`, `--host`, `--room`, `--key`, `--provider`,
`--transport`, `--socks-port`, `--dir`, `--unit`, `--build`, `--no-systemd`,
`--swap`, `--show-key`, `--force`.
